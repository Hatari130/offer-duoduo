目标：把 JobKoI 浏览器插件发布为 **Unlisted（不公开）**。任何拿到商店 URL 的用户都能安装，但商品不会出现在商店搜索与分类页。Unlisted 与公开商品遵守同一套审核政策。

- [ ] GitHub 环境变量 `JOBKOI_API_URL=https://139.196.197.112/api`。
- [ ] Chrome Web Store 开发者账号已完成一次性注册费与身份验证。
- [ ] 开发者后台联系邮箱已填写并完成验证。
- [ ] 商店上传 ZIP 由 HTTPS 环境变量重新构建，包内不得出现 `http://139.196.197.112`。

当前网站上的 `0.1.1` 直接下载包是 IP HTTP 过渡包，**不能上传到 Chrome Web Store**。

## 商店资料

### 基本信息

- 商品名称：`JobKoI - 网申助手与投递管理`
- 默认语言：`中文（简体）`
- 类别：`生产力工具`
- 可见性：`Unlisted / 不公开`
- 官方网站：`https://139.196.197.112/browser-extension`
- 隐私政策：`https://139.196.197.112/privacy`
- 支持页面：`https://github.com/Hatari130/offer-duoduo/issues`

### 单一用途说明

> JobKoI 帮助求职者在招聘网页中复用本人提供的简历资料，识别岗位并辅助填写表单，同时持续管理和同步本人的投递进度。

### 简短说明

> 识别招聘页面，用你的简历辅助填写表单，并把岗位和投递进度同步回同一个 JobKoI 工作台。所有内容均由用户确认后提交。

### 详细说明

> JobKoI 是面向求职者的浏览器网申助手。
>
> - 识别当前招聘页面中的岗位、投递记录和流程变化；
> - 复用用户本人录入或导入的简历资料，辅助填写常见招聘表单；
> - 不自动点击最终提交，所有填写内容均由用户检查和确认；
> - 在插件内管理感兴趣、已投递、笔试、面试和 Offer 阶段；
> - 登录同一个 JobKoI 账号后，将投递记录同步到个人工作台；
> - 支持本地简历资料库以及用户主动启用的 AI 辅助功能。
>
> JobKoI 不出售用户数据，不进行个性化广告，也不会在用户未操作时上传整个网页内容。

## 权限理由

| 权限 | 后台说明 |
| --- | --- |
| `identity` | 使用 `chrome.identity.launchWebAuthFlow` 安全完成 JobKoI 网站账号连接；不读取 Google 账号资料。 |
| `storage` | 在浏览器本地保存用户主动录入的简历、投递、设置、同步游标和待同步队列。 |
| `unlimitedStorage` | 用户可能保存多份带 PDF 与图片的简历，数据量会超过 Chrome 本地存储默认配额。 |
| `alarms` | 定时拉取同账号投递变化和公开招聘机会，避免扩展后台休眠后停止同步。 |
| `scripting` | 在用户操作的招聘页面中注入识别和辅助填写逻辑，并在内容脚本未加载时恢复功能。 |
| `http://*/*`、`https://*/*` | 招聘系统分布在大量独立域名；跨站点识别和辅助填写是插件的单一核心用途。只有用户主动使用时才处理当前页面数据。 |

## 隐私实践勾选建议

按实际功能披露以下数据类型：

- 个人身份信息：姓名、邮箱、电话、地址以及简历中的个人资料；
- 身份验证信息：JobKoI 设备令牌；用户可选的 DeepSeek API 密钥只保存在本地；
- 网站内容：用户主动识别的岗位描述、招聘表单标签和用户要求填写的字段；
- 用户活动：本人投递状态、面试阶段和下一步行动；
- 用户提供的内容：简历、项目经历、备注、对话和面试文字稿。

用途选择：应用功能、账号管理、安全与防滥用。不要选择广告、个性化广告、信用评估或出售数据。

Limited Use 声明已经放在 `/privacy`。提交时应确认：

- 不出售或转移数据用于广告；
- 不允许人工阅读个人求职内容，除非用户针对支持请求明确授权、安全调查、法律义务或匿名聚合分析；
- 个人与敏感数据只通过 HTTPS 传输；
- 数据用途与商店说明中的单一功能直接相关。

## 提交流程

1. 在 Developer Dashboard 新建商品并上传 HTTPS 正式 ZIP。
2. 填写商店详情、图片、隐私实践和支持信息。
3. 在 Distribution 中选择 `Unlisted`，地区按实际服务范围选择。
4. 保存草稿并执行自动检查，解决所有红色错误。
5. 提交审核。Unlisted 也会完整审核。
6. 审核通过后复制商品 URL。
7. 设置 GitHub 环境变量 `JOBKOI_CHROME_WEB_STORE_URL=<商品URL>`，重新运行生产部署。
8. 验证 `/browser-extension` 的“前往商店”按钮可用，并将 `extension-release.json` 的状态切换为已发布。
