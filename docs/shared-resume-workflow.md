# 云端简历模板与本地网申资料（2026-09-22）

## 当前规则

- 网页入口为“简历模板”，用于制作、编辑、岗位定制和导出简历。简历不再自动成为插件填写资料。
- 云端继续使用现有 `resume_templates`、岗位版本与定制任务存储。简历内容、图片和排版按用户账号保存；网页保存继续携带 `expectedRevision`，并发编辑返回 409，页面保留编辑内容及另存副本入口。
- 生产环境沿用 PostgreSQL（生产配置要求 `DATABASE_URL`），不改表、不清表、不重建用户简历。既有 ID、归属、版本、历史定制内容及图片保留；旧 `origin: extension` 条目在网页标为“历史导入”。
- 插件网申资料仅存在本机。用户可手动添加多份空白资料，也可主动从文件导入；每份独立保存完整字段和文案。编辑、切换、删除不会修改其他资料或云端简历。
- 账号连接和后台定时同步仅处理投递记录。插件不再上传、拉取、删除简历，不再自动导入已确认的云端岗位版本。插件“制作简历”入口只打开网页模板，不携带本地资料。
- 服务端拒绝设备会话访问简历模板、岗位版本及定制任务接口，防止旧插件继续写入或删除云端简历；网页会话保留原有能力。

## 插件无损迁移

- 新资料库键：`offerflow.localApplicationProfiles.v1`；当前选择：`offerflow.localApplicationActiveId`；选择缓存：`offerflow.localApplicationProfile`。
- 首次读取时，复制旧 `offerflow.resumes`、`offerflow.profile` 和 `offerflow.applicationProfile` 的有效内容，合并本机补充字段及按简历 ID 保存的网申文案。所有后续读写只使用新资料库，不再叠加全局共享字段。
- 原来的通用版、岗位版都变成独立本地资料。复制继承的 PDF 和图片，解除父子关系，删除一份不会级联删除另一份。旧同步冲突的云端候选内容额外保存为本地副本。
- 旧存储键保留作为恢复备份，不主动删除。历史脱离经历的补充资料仍可在网申编辑页手动恢复。
- 新资料库成功写入后才视为已迁移；重复读取不再写入，迁移失败可重试。主动清空本地资料时同时清理旧备份，保留空库标记，避免旧资料重新出现。
- 单份修改带本地递增版本号，并在写入锁内读取最新资料库；过期保存或已删除资料的旧页面保存会被拒绝，保留页面编辑内容。新增、删除不会覆盖其他页面修改的无关资料。
- 本机资料属于当前浏览器，切换网站账号不会搬运或上传这些资料。

## 发布与回滚

1. 配套发布 API、网页和插件。服务端先阻断旧设备的简历访问，投递同步接口保持可用；旧插件需升级以避免显示简历同步失败。
2. 本次不需要新的 SQL 迁移；保留既有数据库和常规备份即可。
3. 插件升级后首次打开资料页执行本机迁移。云端保存的简历不需另行搬迁。
4. 不应直接回滚到启用简历同步的旧插件：新本地资料不会被旧版读取。旧键仍是升级时快照，并非升级后新增编辑的实时镜像。

## 验证

- `pnpm test`：契约、API、插件同步与隔离测试。
- `pnpm --filter @offerflow/web test`：网页回归。
- `pnpm build`：类型检查、全部构建和插件包验证。
- `node apps/extension/scripts/check-local-profiles-ui.mjs`：隔离浏览器中检查手动新增、空白隔离、显式/自动保存、刷新、切换、并发冲突及删除。
- `node --experimental-transform-types apps/web/scripts/check-resume-templates-ui.mjs`：隔离账号与本地 API 中检查旧云端资料保留、模板新建、自动保存及刷新恢复。

浏览器回归使用独立测试浏览器和合成数据；网页 API 测试使用内存存储，未对生产数据库执行写入或发布。
