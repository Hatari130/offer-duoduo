**安全与账号隔离**

**1. [P1] 插件授权码会被重定向到任意 HTTPS 网站。代码确认，兑换端本地复现。**

位置：[ExtensionConnectPage.tsx:7](D:/2026/2026product/offerflow/apps/web/src/pages/ExtensionConnectPage.tsx:7)、[app.ts:956](D:/2026/2026product/offerflow/apps/api/src/app.ts:956)。

redirect_uri 仅检查 startsWith("https://")，随后自动创建设备码并把 code 附在目标 URL 上。已登录用户打开带外部 redirect_uri 的连接页，就会向该网站发送授权码；state 由链接提供，不能证明回调可信。设备兑换接口又不绑定预先登记的扩展 ID、设备或 PKCE。拿到码可换取用户的设备会话。这里不是已证明攻击者能够猜出账号，而是可信网站会把有效凭据交给任意指定回调。

修复：回调必须精确匹配允许的扩展 chromiumapp.org origin 和固定路径；服务端绑定授权请求、回调、扩展身份与一次性 challenge；未知回调在创建码前拒绝。

**2. [P1] messages 的 UPSERT 可覆盖另一个用户的消息。代码确认，未连接 PostgreSQL 复现。**

位置：[postgres-store.ts:746](D:/2026/2026product/offerflow/apps/api/src/store/postgres-store.ts:746)、[0002_chat_auth_sync.sql:27](D:/2026/2026product/offerflow/packages/db/migrations/0002_chat_auth_sync.sql:27)。

clientMessageId 由客户端提供。appendUserMessage 只按 id + 当前 user_id 查重，但 saveMessage 使用全局 `ON CONFLICT (id) DO UPDATE`，没有所有权条件。若另一用户已存在这个 UUID，SELECT 查不到，INSERT 冲突后却覆盖原行的 content/status/payload。数据库行的 user_id、conversation_id 仍属于原用户，而 JSON payload 已被换成提交方内容。

前提是已知/碰撞到一个有效消息 ID，不能把它描述为“任意读取所有用户消息”。修复应同时约束消息归属和会话归属，禁止跨用户冲突更新，并补真实双用户 PostgreSQL 回归测试。

**3. [P1] 登录和反馈限流信任可伪造的 X-Forwarded-For。本地复现。**

位置：[app.ts:380](D:/2026/2026product/offerflow/apps/api/src/app.ts:380)、[app.ts:607](D:/2026/2026product/offerflow/apps/api/src/app.ts:607)、[nginx.offerflow.conf.example:36](D:/2026/2026product/offerflow/deploy/nginx.offerflow.conf.example:36)。

API 直接使用第一个转发 IP；Nginx 示例通过 proxy_add_x_forwarded_for 追加真实 IP，保留客户端伪造的第一个值。实测同一伪造地址被限流后，替换该头立即从 429 回到普通认证失败 401。邮箱发送的 requesterIp 也读取同一来源。内存 Map 不主动清理旧键、多实例各自计数，会进一步削弱防护并增加内存占用。

修复：在边缘覆盖客户端头，API 只信任明确的反向代理；对账号和来源分别限流，并让多实例共享限流状态。

**6. [P1] 同步期间新增的本地编辑会被旧快照覆盖。代码确认。**

位置：[cloudSync.ts:402](D:/2026/2026product/offerflow/apps/extension/src/infrastructure/sync/cloudSync.ts:402)、[syncState.ts:186](D:/2026/2026product/offerflow/apps/extension/src/infrastructure/sync/syncState.ts:186)、[storage.ts:227](D:/2026/2026product/offerflow/apps/extension/src/infrastructure/storage/storage.ts:227)。

**7. [P1] PostgreSQL 同步游标可能永久跳过变更。代码确认。**
